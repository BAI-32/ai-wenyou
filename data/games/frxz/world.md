# 凡人修仙传人界篇 · 天南地区规则

## 境界划分
修仙境界从低到高为：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫。
- 炼气期：共十三层，初入修仙，可使用低阶法器，寿元与常人无异（约百年）
- 筑基期：寿元两百载，可驱使法器飞行，真正踏入修仙门槛
- 结丹期：寿元五百载，可御器远飞，成为宗门中坚
- 元婴期：寿元千载，一方霸主，可开宗立派
- 化神期：传说中的存在，天南地区数千年未出

## 灵根
灵根分五灵根（金木水火土），属性越纯修炼越快：
- 天灵根：单属性，修炼速度极快，百年内可结丹，各宗门争抢
- 双灵根：修炼速度较快，宗门重点培养
- 三灵根：中等资质，可修炼到筑基
- 四灵根/五灵根：资质低劣，修炼缓慢，多数终生停留在炼气期
- 异灵根：特殊属性灵根（如雷灵根、冰灵根），威力巨大

## 宗门与势力
### 越国七派
- **黄枫谷**：七派之首，剑修为主，位于太岳山脉
- **掩月宗**：女修居多，擅长幻术、媚术
- **灵兽山**：擅长御兽，圈养妖兽
- **清虚门**：道法高深，擅长符箓
- **化刀坞**：刀修宗门，杀伐果断
- **天阙堡**：擅长防御，阵法大家
- **巨剑门**：重剑无锋，体修为主

七派同气连枝，共抗魔道六宗，每五年举办一次血色禁地试炼。

## 物品等级
- 法器：炼气期使用，分下/中/上/极品
- 法宝：筑基期以上使用，需要神识炼化
- 古宝：上古修士遗留，威力巨大
- 通天灵宝：传说级宝物
- 丹药：分一到九品，炼气期用一品丹药，筑基期用二品，以此类推
- 符箓：消耗品，低阶符箓炼气期即可使用

## 重要区域
- **太岳山脉**：黄枫谷所在，灵脉汇聚
- **血色禁地**：越国境内秘境，五年一开，内有筑基丹主药“血凝五行草”，危险重重
- **坊市**：修仙者交易之地，越国最大坊市在京城附近
- **乱星海**：远离天南的海外区域，危机四伏（本阶段暂不开放）

## 世界规则
1. 修仙界弱肉强食，杀人夺宝是常事，不要轻易相信他人
2. 修为越高寿元越长，但突破境界成功率极低，瓶颈难破
3. 灵根资质决定修炼速度，但机缘、丹药、功法也可逆天改命
4. 宗门有门规，私下斗杀禁止在宗门内进行，外出则无人管束
5. 低阶修士在高阶修士面前如同蝼蚁，不要轻易招惹强者
6. 闭关修炼需要消耗大量时间，境界越高闭关越久，期间外界可能发生重大变化

## 常识
- 修仙者通用货币：灵石，分低/中/高阶，兑换比例1:100
- 低阶修士需要为宗门做事换取灵石、丹药、功法
- 散修没有宗门依靠，修炼更加艰难，死亡率极高
